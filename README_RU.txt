ТРОПЫ ЭЛЬДОРИИ — v35
====================

СОСТАВ
  game.py              — точка входа (флаги: --version, --windowed, --reset-settings)
  tropy/               — код игры
  assets/              — спрайты, иконка, шрифт (assets/fonts)
  tools/gen_assets.py  — генератор спрайтов (нужен Pillow)
  tests/               — автотесты (python -m unittest discover -s tests -v)
  installer/           — скрипт установщика Inno Setup;  version_info.txt — метаданные exe
  docs/                — план релиза, чек-лист, тексты для магазина;  CHANGELOG.md
  EULA_TEMPLATE_RU.txt, PRIVACY.txt, THIRD_PARTY_NOTICES.txt — юридические шаблоны (нужна проверка юристом)

ЗАПУСК И СБОРКА
  Из исходников: pip install -r requirements.txt, затем python game.py (Windows: start_game.bat).
  EXE: build_exe.bat -> dist\Tropy Eldorii\Tropy Eldorii.exe.
  Полный релиз (exe + portable zip + установщик): запустите workflow «Build Windows release» на GitHub
  (при публикации тега v* релиз создаётся автоматически).

УПРАВЛЕНИЕ (клавиши можно переназначить в Настройки → Управление)
  WASD / стрелки — движение     SPACE / ЛКМ — атака     R / ПКМ — навык оружия     Q — импульс     SHIFT — рывок
  H — зелье   E — действие   1–4 — активные навыки   I сумка · C герой · K навыки · J журнал · M карта
  ESC / F10 — пауза   F5 / F9 — сохранить / загрузить   F11 — полный экран   F3 — счётчик FPS
  Геймпад: левый стик — движение, правый — прицел, X — атака, RT — атака, LT — навык, RB — навык оружия,
  LB — импульс, B — рывок, A — действие/выбор, Y — зелье, D-pad — навыки 1–4 (в меню — перемещение), Start — пауза.

ЧТО НОВОГО В v35
  - Исправлен критический сбой запуска v34 (метод run затенялся словарём забега). Игровой цикл теперь защищён:
    ошибки пишутся в game.log, при серии сбоев игра сохраняется и закрывается.
  - Встроенный шрифт, 3 слота сохранений (перенос из v32–v34), учёт времени игры.
  - Геймпад, переназначение клавиш, настройки (экран, звук, игра, управление).
  - Доступность: 3 уровня сложности, тряска экрана, щадящие вспышки, числа урона, режим для дальтоников,
    упрощённая графика. Подсказки в контексте.
  - Достижения (28), кодекс, рекорды, история забегов, титры.
  - Бездна: накал (6 модификаторов), ежедневный забег, сид.
  - Оружие: молот (дробящий урон) и лук. Элитные враги. 10 новых свойств предметов (всего 28). 9 новых заданий.
  - Освещение в подземельях, окружающие частицы, мини-карта комнат с туманом, музыка по областям и боссам.
  - Установщик, метаданные exe, CI-публикация релиза.

СОХРАНЕНИЯ
  Папка: %APPDATA%\TropyEldorii (Windows) или ~/.local/share/TropyEldorii.
  eldoria_v35_slotN.json (+ .bak, .archive.json), profile_v35.json (души, достижения, кодекс), settings_v35.json,
  game.log (журнал ошибок). Бездна не сохраняется.

ЧТО ЕЩЁ НУЖНО ДЛЯ КОММЕРЧЕСКОГО ВЫПУСКА
