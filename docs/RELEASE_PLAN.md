# План доведения «Тропы Эльдории» до коммерческого релиза

Составлен по результатам сравнения с образцами жанра (Hades, The Binding of Isaac, Dead Cells, Vampire Survivors,
Diablo-подобные) и стандартными требованиями Steam-релиза (управление геймпадом, настройки доступности, сохранения,
достижения, стабильность, лицензии).

## Что делают образцовые игры, и где мы

## Блокеры релиза, которые нельзя закрыть кодом
1. **Живое тестирование** на нескольких ПК и геймпадах (я проверяю логику автотестами, но не вижу и не слышу игру).
2. **Балансировка** по результатам игровых сессий (числа врагов, боссов, реликвий).
3. **Профессиональный звук и музыка**, при желании — полноценная покадровая анимация.
4. **Локализация** (английский первым): вынести строки из кода в таблицы и отдать переводчику.
5. **Юридическое**: правообладатель, EULA и политика конфиденциальности (шаблоны приложены, нужна проверка юриста),
   возрастной рейтинг, налоги/ИП, цифровая подпись кода (сертификат).
6. **Steam**: аккаунт, Steamworks SDK (достижения, облако), страница, капсулы, трейлер, вишлист-кампания.
7. **Поддержка**: канал для отчётов об ошибках, обработка отзывов, план патчей.

## Порядок работ до релиза
1. Закрытое тестирование (5–10 игроков), сбор game.log и замечаний.
2. Исправление ошибок и баланса, повторное тестирование.
3. Локализация, финальная музыка, подпись сборки.
4. Страница магазина, трейлер, публикация.
5. План обновлений (новые боссы Бездны, оружие, события).
